# Onboarding provider icons

These SVGs are bundled locally so onboarding works offline and makes no favicon requests.

- `google.svg`, `duckduckgo.svg`, `brave.svg`, `startpage.svg`, `youtube.svg`: Simple Icons project, downloaded from its `develop/icons/` directory. The project is licensed CC0-1.0: https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md
- `bing.svg`: Bootstrap Icons project, downloaded from `icons/bing.svg`. The project is licensed MIT: https://github.com/twbs/icons/blob/main/LICENSE

The provider labels and selection behavior remain supplied by the app settings. Icons are decorative (`alt=""`, `aria-hidden="true"`).
