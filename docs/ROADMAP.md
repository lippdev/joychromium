# Roadmap de plataformas

O alpha atual do JoyChromium é limitado ao Windows. Estes itens acompanham plataformas futuras; nenhum deles bloqueia o alpha Windows.

| Plataforma / entrega | Estado | Issue |
|---|---|---|
| macOS | Planejado; fora do alpha Windows | [#108](https://github.com/lippdev/joychromium/issues/108) |
| Linux, Wayland e Flathub | Planejado; fora do alpha Windows | [#109](https://github.com/lippdev/joychromium/issues/109) |
| Steam Deck / SteamOS Gaming | Planejado; depende do trabalho Linux | [#110](https://github.com/lippdev/joychromium/issues/110) |
| Orca (Linux) e VoiceOver (macOS) | Validações futuras vinculadas às plataformas correspondentes | #108 / #109 |

Os guias técnicos existentes continuam disponíveis como referência de implementação e histórico, mas não indicam suporte atual: [Wayland e Steam Deck](WAYLAND.md), [leitores de tela](SCREEN-READER.md), [Flatpak](../flatpak/README.md) e [DRM/EVS](DRM-EVS.md).
