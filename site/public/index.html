A internet inteira, do sofá.

Um navegador para a TV que você comanda só com o controle. Sem mouse, sem teclado, sem levantar.

Só escrevemos quando houver uma versão nova para testar.

Pegue o controle. O resto ele faz.

  1. O analógico é o seu mouse

    O cursor anda pelo app inteiro, das abas à página, e vira mãozinha sobre o que dá para clicar. A clica; dois toques, clique direito.

  2. O D-pad pula de item em item

    Cada direção leva ao próximo link ou botão, e o cursor vai junto, como no Edge do Xbox.

  3. Um teclado de console

    Y abre o teclado na barra de endereço. X apaga, LT maiúsculas, Start envia.

  4. Depois é só assistir

    O analógico direito rola a página, LT e RT trocam de aba, B volta. YouTube e Twitch ganham setas nativas.

O que o JoyChromium promete.

  • 01

    Controle primeiro. Sempre.

    Cada tela, menu e campo de texto funciona com o gamepad. Mouse e teclado continuam ali para quando você quiser.

  • 02

    Sem anúncios. Sem rastreadores.

    Bloqueio integrado, ligado desde a primeira página, e HTTPS estrito. A TV é sua, não do anunciante.

  • 03

    Feito para três metros de distância.

    Letras grandes, foco que se enxerga do sofá, tela cheia de cara. Xbox, PlayStation, Switch Pro e 8BitDo.

  • 04

    Grátis, com o código à vista.

    Sem conta, sem assinatura. O código está público no GitHub para quem quiser ver como funciona.
